# 当前边界

- RRM 记录模型显式产出的节点与运行时的数据交付。隐藏思维链、模型内部因果使用和自然语言推断的正确性均无法从运行日志证明。
- 操作目标和工具参数是可检查的规划控制信息。自定义适配器应将推断产物写入节点，保持执行调用无隐藏历史。运行时无法判定自由文本目标中夹带的语义判断，也无法审计自定义适配器的内部上下文。
- SHA-256 检查用于发现快照与存储记录不一致。能够同时重写内容、哈希和事件的存储方仍可篡改历史。
- `current` 表示版本仍可用于执行。独立验证记录提供额外的检查结果。修订及撤销会传播失效，验证失败本身不会自动撤销数据。
- 适配器超时后，运行时停止等待并拒绝提交迟到结果。Python 工作线程内的第三方调用及已触发的外部副作用可能继续存在。运行时不会自动重发有副作用的工具操作。异常进程退出可能留下 `running` 记录，原型可回放和检查该状态。
- Token 预算按提供方返回的用量计算，请求可能已经产生额外用量。规划只保留最近 20 个可用结果及问题，长节点会截断显示，执行器仍收到选中节点的完整内容。
- 原型在读取时从完整事件流重建图。SQLite 连接通常由单个线程使用。存储层可按 [架构扩展点](architecture.md) 接入更高吞吐的后端。
