# 当前边界

- RRM 记录模型显式产出的节点与运行时的数据交付。隐藏思维链、模型内部因果使用和自然语言推断的正确性均无法从运行日志证明。
- 操作目标和工具参数是可检查的规划控制信息。运行时无法判定自由文本目标中夹带的语义判断，也无法审计自定义适配器的内部上下文。
- SHA-256 检查用于发现快照与存储记录不一致。能够同时重写内容、哈希和事件的存储方仍可篡改历史。逐步来源检查验证本地快照，权威版本匹配需要显式配置 SourceAdapter。
- 规划使用图结构与关键词启发式选取有限摘要。很大的图可能仍有未选中的相关节点。摘要预算以节点数和字符数衡量，工具 Schema 和原始任务文本另计。
- 超时或取消后，运行时停止等待并拒绝提交迟到结果。适配器可协作响应取消信号，无法协作的第三方调用及已触发的外部副作用可能继续。记录中的 `exited` 仅表示本地适配器调用结束。传输超时后远程系统仍可能已接收或执行请求。
- 调用方应在确认原执行已停止后触发异常恢复。恢复不会调用模型或工具，也无法判定外部副作用是否成功。结果未知的非幂等工具需由调用方核对并确认。接续阶段由模型提出新操作，开发者仍应在有副作用的工具内实现业务幂等约束。
- Token 预算按提供方返回的用量计算，请求可能已经产生额外用量。时间预算覆盖执行等待，持久化和本地验证需要各自完成事务与结算。
- 原型在读取时从完整事件流重建图。SQLite 连接通常由单个线程使用。存储层可按 [架构扩展点](architecture.md) 接入更高吞吐的后端。
